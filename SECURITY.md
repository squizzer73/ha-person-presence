# Security reporting

If you find a security issue, please [report it privately through GitHub](https://github.com/squizzer73/ha-person-presence/security/advisories/new). Private vulnerability reporting is enabled for this repository. Please don't post vulnerability details in a public issue.

Include the Person Presence and Home Assistant Core versions, what you found, the possible impact and steps to reproduce it using fictional people and places. I maintain this as a community beta, so responses are best effort rather than a guaranteed turnaround.

Never include credentials, raw provider payloads, real coordinates, Bluetooth identity keys or unredacted household diagnostics. Inspect the whole diagnostics download before sharing it, including metadata added by Home Assistant. A private report does not need your household secrets.

For ordinary bugs, testing results, suggestions and ideas, use [GitHub Issues](https://github.com/squizzer73/ha-person-presence/issues) or the [beta feedback form](https://github.com/squizzer73/ha-person-presence/issues/new?template=beta_feedback.yml).
