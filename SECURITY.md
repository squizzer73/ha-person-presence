# Security reporting

Person Presence is a public beta. A private security-reporting channel is not yet configured. Until it is available, contact the maintainer with a public issue requesting private contact, without describing the vulnerability or sharing sensitive details. Do not assume a private reporting endpoint is enabled.

Never post credentials, raw provider payloads, coordinates, Bluetooth IRKs or unredacted household diagnostics in public issues. Inspect the entire diagnostics download before sharing, including metadata added by Home Assistant.
