# Support

Person Presence is a community beta maintained by @squizzer73. Support is best effort, with no guaranteed response time. It is not an official Home Assistant, Apple, Bermuda or iCloud3 product.

Once the repository is published, use GitHub Issues for reproducible bugs and feature requests. Include the integration version, HA Core version, provider names, expected versus observed behaviour, approximate delays and whether the device was carried, charging or worn. Replace household names with fictional names.

Check docs/troubleshooting.md first. Unknown can be the correct result when observations are stale. Wearing cannot be inferred from not charging. Independent watch-only outdoor tracking depends on the source provider.

Inspect diagnostics before sharing: HA adds its own metadata to the integration payload. Never post coordinates, raw provider payloads, Bluetooth IRKs, access tokens or private configuration. Security concerns follow SECURITY.md.
