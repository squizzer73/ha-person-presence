# Person Presence 0.3.0b2 — presence and lookup fixes

This beta fixes four bugs found during a code review of 0.3.0b1.

## What's changed

- Moving between rooms no longer drops to Unknown just because an older away GPS fix is still within its age window. Newer away evidence and local negative signals still clear stale home presence immediately.
- Automatic Bermuda guards now consider freshness when selecting between matching trackers. A stale first tracker no longer hides a fresh alternative. Newer or equal-time away signals take precedence; explicitly mapped guards are unchanged.
- Optional place lookup can recover for the same still-valid GPS fix after an error. Requests respect the provider's backoff and a minimum one-minute delay; changing device, stale evidence, disabling lookup or unloading prevents obsolete retries/results.
- Switching the lookup endpoint resets the previous provider's error backoff. Shared request spacing remains in place, and clearing the cache alone does not bypass an existing provider backoff.

## Upgrading

Back up Home Assistant, install this beta and restart once. Existing entries, mappings, entity IDs, dashboard layouts and optional-lookup settings are preserved. There are no new entities. The family card code is unchanged, so its resource URL stays the same.

Place lookup remains off unless you previously configured and enabled it. No provider account or location settings are changed by upgrading. Source limitations and the need for real phone/watch field testing still apply.
