# 0.4.0b1 — Easier optional place lookup

- Geoapify setup with one masked API key, helpful text and explicit Test or Skip.
- One shared household service with a separate enable switch for each person.
- Lookup off by default; advanced custom services remain supported.
- Safe Geoapify/OpenStreetMap attribution links on the family card.
- Unsaved drafts preserved; concurrent edits rejected for review; blank keeps the key and explicit removal clears it.
- Existing entity IDs, tracking rules and 0.3.0b2 bug fixes preserved.

Testing uses a public example coordinate and may consume one credit. Automated validation uses fictional keys and responses; a real Geoapify account has not been tested in this release.
